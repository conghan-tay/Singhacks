# SingHacks 2026 — Julius Baer Wealth Intelligence

**The Contingency Desk** — per client, a book of *armed contingency plans*. Each plan is a trigger
condition on an observable variable, the consequence traced through that client's actual positions
and look-through exposures, a ranked action set and a client-ready script — authored by an agent,
reviewed and **armed by the Relationship Manager before the event**, watched continuously, and
fired the moment the trigger hits.

The arming step is the governance artefact: the reasoning was signed by a human *before* the market
moved, so no post-hoc rationalisation is available to it.

> **A trigger is never evaluated by a model.**

## Quick start

```bash
cd contingency-desk
pip3 install --break-system-packages pytest jsonschema pandas
python3 verify.py --write          # recompute every number from the dataset
python3 -m pytest tests/ -q        # 37 assertions
python3 engine.py                  # the book at three Brent levels
python3 store.py                   # a full DRAFTED -> ACTIONED walk with its decision log
```

## The finding

Hartono Wijaya Kusuma's mandate report is green in every band. It is green because 41.42% of his
wealth — a single Indonesian coal stock — sits in a **custody** account, which no mandate measures.
The same name is a worst-of leg in his structured note and the collateral for an SGD 8m Lombard
facility. That facility breaches its 70% margin call if Brent falls to **78.85**.

Brent was 72.40 the day before the conflict began. The client is one de-escalation away from a
margin call, and nothing on his report says so.

Every figure above is recomputed from the dataset by
[`contingency-desk/verify.py`](contingency-desk/verify.py) and pinned by a test.

## Data

All data in `singhacks-jb-wealth-intelligence/` is **synthetic**, generated by the organisers for
this hackathon. No real client, portfolio, holding or instrument is represented. Market levels and
the event log are calibrated to real 2026 market history so that portfolio behaviour is explainable.
